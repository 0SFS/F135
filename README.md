# F135

The F135 engine used by the F-35B: geometry, generated optical data, and the scripts that rebuild those artifacts. `fly` checks them with `npm run verify:engine-assets` and `npm run verify:exhaust`.

The fly app depends on this package and runs its tests. From the `fly` directory, `npm test` includes them.
